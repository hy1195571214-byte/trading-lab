# 本地交易工作台标签面板验收

日期：2026-11-09。仅本地修改和验证，未推送、上传或部署。

右侧统一为五个标签：决策、账户、成交、Agent 过程、专家。账户仅显示所选历史日快照、持仓和截至当日的资产曲线；专家标签明确显示实验当前团队，待生效团队单独标记。像素专家工牌与原有团队编辑器保留。原先下方重复的专家、持仓、过程和资产曲线区域已合并。

验证环境：本地 5175 前端 + 原有 8000 后端；已有确定性合成演示实验 `03634dca-f7f9-4471-8015-055fcb4da57b`。没有新增模型调用，没有修改实验数据库。

- TypeScript 与 Vite 生产构建通过。
- 五个标签逐个切换通过，选择日期保持一致；刷新及切换检查期间无 pageerror。
- 标签切换没有发起 API 请求。
- 从 2023-01-06 成交的“查看来源建议”跳转至 2023-01-05，并自动激活决策标签。
- 左右方向键可切换并聚焦标签。
- 专家标签可打开原有团队编辑器；检查后取消，没有提交变更。
- 1440、1024、390 像素宽度下无页面水平溢出。
- 工作区三个源码文件与本地运行镜像的 SHA256 一致。
