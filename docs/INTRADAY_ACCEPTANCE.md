# 分钟回放与前向模拟：本地验收

验收日期：2026-11-09。仅本地修改、调试和验证，未推送、上传或更新公网服务。用户尚未注册 Alpaca，本轮没有使用真实行情凭据、没有调用付费模型，也没有券商订单。

## 已实现

- 独立 v2 时间模型，支持 1 分钟/1 小时历史数据、多天回放、单独配置决策间隔及持仓上限。原有 v1 日频实验保留旧引擎。
- 时间戳 CSV、明确标识的合成数据生成、Alpaca IEX 只读历史导入和 1 分钟行情采集适配器。数据凭据独立加密保存，写入后不回显。
- 历史订单按决策完成后首个合格开盘执行；前向订单按提交后新观察到的合格收盘价模拟执行，记录实际观察时间及来源 K 线。
- 重复消息去重、晚到行情与修订记录、过期行情/建议保护、人工批准/修改/拒绝、持仓到期系统退出、配置冻结和审计轨迹。
- 分钟 K 线的决策/成交标记、来源建议跳转、所选时点的账户与专家意见；保留紧凑控制栏、折叠侧栏和右侧标签页。
- 真实 LLM 输入使用冻结的窗口限制：每标的最多 200 根 bars、最近 90 个账户点，并受总字符与原有调用/预算限制保护。加速合成行情禁止真实 LLM 模式。

## 当前限制

- Alpaca 只完成适配和替身测试，未用真实账户联网验收；IEX 不能称为全市场成交数据。免费权益以账户实际权限为准。
- 没有验证真实 LLM 的分钟/前向运行。此前有额度上限的日频模型测试不构成本轮付费授权。
- 真实流目前仅支持 1 分钟 bars；没有 5/15 分钟重采样、完整交易所节假日日历或 tick 级撮合。
- 持仓时限是经过的 UTC 时间，1d=24 小时；休市、缺失报价会延迟实际退出。合成行情只模拟工作日结构，不是交易所日历。
- v2 自动配对的买入持有基准报告尚未实现；可单独建立 v2 基准实验比较，不能将缺失结果视为零收益。
- 实时采集需要本地服务持续运行。没有验证大规模长时间常驻负载、远程多用户使用或新的公网部署。
