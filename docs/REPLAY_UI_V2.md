# 可读交易回放工作台 v2

确认来源：用户 2026-11-09 指出原演示缺少 K 线、难以看清 Agent 操作。本次在现有黑灰/黄绿界面上改进，不修改交易策略或历史结果。

## 页面阅读顺序

1. 选择实验、标的和已回放日期。
2. 查看真实 OHLC 日 K 线及成交量，区分 AI 建议标记与已执行 BUY/SELL 标记。
3. 查看当天交易专家意见、顾问意见、协调后的唯一建议、审核记录及执行结果。
4. 核对当日持仓、现金，以及辅助的账户净值曲线。

## 回看与运行

- “回看记录”只切换已有交易日，支持前后一天及自动播放，不发送 run/step/review 请求，不产生模型费用。
- “推进实验”使用原有模型/演示运行路径，与回看分区；需审核的建议仍阻塞推进。
- K 线来自固定数据集 OHLCV，不把账户净值改画成假 K 线。
- 选择过去日期时，行情图表和当日持仓只展示该日期及之前的记录。
- 建议、批准、排队和实际成交分别标注；本日收盘建议不会显示成本日已成交。

## 记录真实性

- 展示的是模型实际输出的依据、风险与结构化结果，不宣称展示模型内部推理。
- 旧实验只有逐日最终决策、审核和订单。未记录日期的专家调用不得按数组下标或当前专家卡拼成历史过程；必须显示记录缺失提示。
- 新实验按尝试保存日期、关联决策、专家输出、协调结果和失败。失败尝试不覆盖前次记录。
- 原始模型语言保留；动作、阶段、字段解释使用中文。不能将机器翻译伪装为原始输出。
- 不额外调用付费模型来生成讲解或重新跑历史实验。

## 数据接口

GET `/api/experiments/{id}/market?as_of=YYYY-MM-DD&symbol=...` 只返回固定数据版本、配置日期与股票池内、截至已运行时点的行情。请求未来日期应拒绝；尚未运行返回空行情。只读查询不改变实验或记录。
