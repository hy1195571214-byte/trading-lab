# Trading Lab 日频回放补采清单

记录于 2026-11-22。此清单保留上一轮讨论的补采范围。SPY 加现金、20 个连续交易日和纽约时间 17:00 都是首轮验收建议，正式实验参数待定。

## 观察范围与可交易范围

- [ ] 覆盖美股市场的宏观、宽基、行业和公司事件。记录每个来源的实际覆盖、历史起止、时间精度及使用权限。
- [ ] 首轮用 SPY 与现金测试大盘择时。若正式实验包含选股，另补历史可交易股票名单、成分变更、代码变更、退市及停牌，按每个决策日当时可获得的信息构建股票池。
- [ ] 选择一段包含宏观发布与盘后财报的连续交易日。另留足够的预热期供技术指标使用，绩效从实验起始日计算。

## 补采与整理

| 优先级 | 数据 | 需要交付的内容 | 来源候选 |
| --- | --- | --- | --- |
| 1 | 市场新闻与宏观事件 | 在明确的来源范围内保留每天取得的报道和事件，涵盖央行、通胀、就业、利率、行业及公司。保存标题、摘要、链接、主题、首发或最早可证实的收录时间与版本。 | Fed、BLS、BEA 发布档案，另评估 GDELT 和校园授权新闻档案的历史覆盖、时间精度及自动分析权限。 |
| 2 | 每日行情、市场宽度与公司行动 | SPY、宽基或主要行业 ETF 的开高低收、成交量、复权口径、分红、拆股及缺失记录。扩到全市场时增加上涨下跌家数、创高创低比例和行业强弱。用截至当时的数据派生均线、收益率、回撤、波动率与量能变化。 | 小样本可沿用现有 Yahoo Finance 采集方式，正式股票池核对学校能否使用 WRDS/CRSP 等历史数据。 |
| 3 | 财报与申报 | 保存原件链接、原始申报号、资金单位、财务期、公开时间及修订版本。提取营收、利润、现金流、负债等字段。对可核实先行公开的业绩公告，保留其独立时间戳和原始版本。 | SEC EDGAR 和可核实的公司业绩公告档案。 |
| 并行 | 仓位和账户 | 由模拟账本逐日生成持仓、现金、净值、回撤、风险敞口、订单及成交。冻结初始资金、费率、滑点和仓位约束。 | Trading Lab 模拟执行与审计记录。 |

现有十股日线和 SEC 资料可用于流程验收。现有十股新闻用日期加延迟来估计可用时间，原始发布时间缺失。当天市场反应实验优先使用新补、时间可核实的市场新闻。

## 角色、时间与验收

- [ ] 数据 Agent 读取行情、技术指标和结构化财务事实。新闻 Agent 读取宏观、行业、公司新闻和业绩事件。仓位 Agent 综合两份分析与账户快照，提交目标权重。
- [ ] 每个交易日先处理已排队的开盘成交，再在固定时点冻结当日信息。首轮建议纽约时间 17:00 决策、下一交易日最早开盘执行。截止后事件进入下一次决策。
- [ ] 每条输入保留原始时间、可用时间、数据版本、来源及证据 ID。服务端按 `available_at <= decision_at` 生成只读快照。Agent 只能读取该快照和同一时间边界内的检索结果。
- [ ] 面向宏观、行业和公司事件设置独立检索覆盖，记录检索命中的证据、截断与缺失。原始档案以明确的来源范围描述覆盖。
- [ ] 验证未来新闻、财报修订和下一交易日开盘价在决策前不可见。修改未来数据后，重新生成早期输入，核对其内容一致。
- [ ] 首轮验证 20 个连续交易日后，以相同账户、区间、成本、执行规则和仓位约束比较固定基准、数据加仓位、新闻加数据加仓位。最终评估留出独立时间段。
