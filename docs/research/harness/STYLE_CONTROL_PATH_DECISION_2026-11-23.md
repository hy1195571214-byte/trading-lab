# 交易风格控制路径：先选择一个主要决策机制

日期：2026-11-23。性质：研究建议，**未修改运行时、既有配置、融合权重或实验结果**。本次只核读本地原始论文和项目合同；未进行网络搜索，也未确认是否有更新文献。

**后续决定：用户已于同日明确确认“用 LLM 系统提示词影响交易决策”。该方案已从研究建议提升为项目开发规则，见 `outputs/PROJECT_CONSTRAINTS.md` 第 13 节与 `docs/IMPLEMENTATION_CONTRACT.md`。风格只在主交易 LLM 系统提示词生效；下文有关权重路径及混合消融的讨论保留为研究背景，不构成启用或叠加机制的授权。当前仅更新规则文档，代码迁移与验收待实施。**

## 判断与建议

如果研究目标是“让 Agent 按某套公开投资理念处理相同证据”，建议先选 **独立分析报告 → 唯一带风格条件的 LLM 交易决策阶段 → 固定程序风控 → 模拟执行**。风格只在交易决策阶段注入；分析员提供按统一口径组织的事实、正反证据、来源、时点和缺失说明，不按交易员风格预先放大分数。分析员仍可能有模型偏差，“不注入风格”不等于已经客观无偏。

这是为了让风格来源和行为归因更清楚的设计选择，**不是论文已证明其收益更高，也不是声称能复现真人交易员**。以真人命名时，应称“依据公开理念构建的模拟”，并在后续实施前核验该理念的原始来源。

如果目标实际是“可复现地控制三类信号贡献，并让用户明确调权”，则选 **独立统一评分 → 唯一确定性加权／阈值／分配引擎 → 同一程序风控 → 模拟执行**。此时风格由权重、规则、持有期等冻结配置定义，LLM 可解释建议，但不再次按角色自由改写交易决定。不能仅将某组权重命名为某位投资者，就宣称建立了他的决策模型。

两条路均可研究；不必先叠加。按当前“模拟交易风格／交易员”的目标，优先验证前一条，后一条作为可审计的架构对照。

## 为什么叠加可能重复放大

假设统一评分是行情、新闻、财务三个 `s_i`。加权引擎形成 `S = Σ w_i s_i`，然后又让被提示为“强烈追随动量”的交易员看到已偏重行情的综合分，再自由偏重行情，便可能对同一偏好连续施加影响。这个风险在上游评分也被同一风格改写时更大。

但这不是数学上必然的“重复计算”：LLM 并非已知的第二个线性加权器，可能放大、抵消或忽略输入。不同权重也可能用于预先验证的数据可靠性或缺失处理，未必表达交易风格。需要先标明每个机制的目的，再用行为实验判断影响。跨来源重复引用同一事件，属于另外一种证据重复，需要来源／事件去重，单选某条风格路径不能自动解决。

还要区分**来源权重**与**因子暴露**：行情、新闻、财务是信息来源分类，动量、价值、质量是策略特征／经验因子；新闻也可能表达价值信息，财务信息也可能被动量策略使用。调高财务来源权重不等于建立价值因子暴露。把三个模型分数都限制在 `[-1,1]`，只统一了数值范围，并未证明相同数值具有可比的预测含义或经过校准；需要统一目标与期限，再在训练／验证区间检验，不能把加权公式本身当作有效性的证据。

## 风格偏好与硬风控必须分开

“更偏动量”“更看重估值”“愿意等待多久”属于产生候选交易的偏好。现金、集中度、总敞口、换手和成交时序属于执行可行性约束。固定程序风控检查／拒绝超限建议，是两条路线共享的必要执行层，并不因为放在 LLM 之后就构成对 alpha 偏好的第二次放大。若所谓风控又以主观行情判断提高或降低方向分，它已在参与策略决策，应单独标记和评估。

比较架构时共享同一组风险限制和拒绝／修订规则，同时保存风控前建议与风控后目标。若要研究风险偏好本身，另立实验因素，避免把仓位上限差异混入“风格提示效果”。无论选择哪条路线，模型不得直接修改账本或下真实订单。

## 最小验证与以后才需要的混合消融

先做三个独立实验臂：统一输入下的中性 LLM 基线、仅交易阶段加入风格的 LLM、仅规则／权重体现风格的确定性引擎。前两臂检查提示是否实际改变行为，第三臂帮助判断增加 LLM 综合是否值得。这里同时改变了最终决策机制，属于**架构比较**，不能据此估计提示与权重的交互作用。

共用冻结的分析报告、时点、资产、初始资金、成本、硬风控和下一可成交时点；保留全程轨迹。区分同一账户快照上的建议差异与独立闭环回测，因为各自交易后，持仓会自然分叉。使用时间外留出区间，模型臂重复独立调用；固定可控生成参数并记录实际调用版本、成本与失败，不假定设置随机种子即可完全复现。预先定义风格行为指标，例如价值型对估值和安全边际证据的反应、动量型对趋势确认和反转证据的反应，以及换手、持有期、证据引用、建议一致性。收益、回撤、风险暴露和成本一并观察；自然语言自述不是风格遵从的充分证据。本次不承诺未经验证的通过阈值。

只有两种单一路径均显示独立价值、且有明确混合假设时，再设计 `风格提示：关／开 × 风格权重：基准／风格化` 的 2×2。四格必须保持同一决策流水线、同一个最终决策模块、同一候选生成与权重作用位置，仅切换这两个因素。例如，固定“评分引擎生成候选 → 同一 LLM 作最终建议”的混合流水线，四格均保留该流水线；权重因素只切换候选引擎的权重，提示因素只切换最终 LLM 的风格条件。基准权重与风格权重提前冻结，均不能依据留出收益选择。

如此才可在预先定义的行为或绩效统计量上考察交互量 `Y11 − Y10 − Y01 + Y00`。如果开关权重时同时把最终决策者从 LLM 换成程序，该交互已被架构变化混淆。即使有效 2×2 出现交互，也只说明该实现中两因素的联合影响，不能单凭它证明心理意义上的“偏差重复”。
