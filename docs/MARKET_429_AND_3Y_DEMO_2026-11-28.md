# 行情 429 修复与三年数据演示

2026-11-28。本次用户明确授权发布修复、将已有三年数据和新闻导入现有公网工作区，并创建不调用 LLM 的演示实验。

行情读取先前仍转发给计算服务；已复现实验列表 200 而行情接口 429。日线图表现在直接从同一数据库读取实验固定的数据版本，验证回放截止日期、标的和校验值；分钟线计算仍由原 Python 引擎处理。图表只对读取时的 429 做最多三次尝试，尊重 Retry-After，切换实验或回放时点时取消旧请求，持续受限时给出冷却后的重新加载按钮。

只导入已有十只股票的历史快照：10,030 条 2022–2025 日线（2022 数据保留为预热资料，研究区间为 2023–2025），110,326 条标题级新闻、7,422 条财务事实、570 条 SEC 申报。重复行情按内容去重。原始数据不提交到公开源码仓库。新闻仅含标题元数据与来源链接，保留日期级来源、派生可用时间和引用限制；不声称拥有新闻全文或完全点时数据。

演示使用平台现有动量规则：根据最多 20 个可见收盘间隔筛选正动量股票，在仓位限制内等权配置，按下一交易日开盘模拟成交。初始资金 100,000，手续费和滑点各 5 个基点，单股上限 25%，只做多。使用原有引擎实际完成 752 个交易日，不合成 LLM 输出，模型调用和预算均为零。规则允许初期较短窗口；2022 数据保留在库中，不虚称本实验使用了整年预热。

实验冻结新闻证据包并提供随回放时点过滤的同期新闻。新闻只用于展示背景，不驱动这套规则，也不做来源或风格加权。标题可见截止为所选日纽约时间 16:00，且不得晚于实验当前进度；来源中“日期加两天”的派生边界不等于精确发布时间。

发布使用固定哈希清单、分块和断点检查，保留旧数据、专家、实验、设置、凭据与审计记录。一次性导入入口在完成后移除。完整发布与验收结果另存 outputs 中，不以构建成功代替线上读取验证。
