# 三年真实市场数据包：来源、覆盖及使用边界

数据范围：2023-01-01 至 2025-12-31；另有 2022-01-01 至 2022-12-31 用于滚动窗口预热。标的为 AAPL、MSFT、AMZN、NVDA、AMGN、COST、GOOGL、META、QCOM、TSLA。它们按可获得三年历史新闻选取，并非按收益挑选；集合科技股偏重，包含医药、零售及汽车，且只包含后来仍可取得资料的公司，因此存在显著的可得性和幸存者偏差，不代表整个市场。

## 已实际保存并校验

- `data/research_3y/normalized/daily_ohlcv.csv`：10,030 条行情；其中三年研究区间 7,520 条，预热期 2,510 条。`adjusted_close` 单列。原始响应为 `raw/yahoo/SYMBOL.json`。
- `normalized/indicators.csv`：每个交易日根据截至当天提供的 close 计算 SMA20、SMA50、SMA200、单日简单收益率、20 日收益率样本标准差年化（乘 sqrt(252)）。不满窗口留空。它们不修复价格供应商的历史修订、拆股或分红问题；不是估值或盈利预测。
- `normalized/corporate_actions.csv`：来源返回的股息、拆股事件单列保存，切勿和复权收益重复计入。
- `normalized/fundamentals.csv`：63,259 条 2022–25 期间 10-K/10-Q 及修订申报的 SEC XBRL 事实，保留原单位、概念、财务区间、申报号、接收时间和延迟后的可用时间。0 条未匹配到接收时间；不同申报/修订的同一财务期保留为独立记录。
- `evidence.jsonl`：570 条 SEC 申报元数据、7,422 条筛选的常用财务概念事实和 110,326 条标题级新闻；无策略结果、模型调用或交易结果。字段为 `id, kind, symbols, title, source, url, event_at, published_at, available_at, content, provenance`。见下文对时间的限制。
- `raw/news_selected_metadata.parquet` 保存最终十只股票 2023–25 筛选前的 139,407 行新闻元数据，`news_coverage.csv` 和下表分别给筛选前/后数量。原始 131,877,177 字节上游完整快照已下载并计算 SHA-256，保留在 `news_source_receipt.json`；为缩小本地包，仅保存所需元数据列，并未保留完整源文件。完整源包含后来生成的模型情绪、解释等字段，均未导入本包。
- `validation.json` 为程序检查结果，`manifest.json` 保存文件的 SHA-256、大小及快照时间；包约 300 MB，验证时需保留 JSONL 原字节。

新闻筛选方法是标题包含公司名或明确产品名，然后按公司、日期、标准化标题去重。它会漏掉未写公司名的相关新闻，也可能保留同名或无关标题，不等于人工核验的相关性。Google News 链接是聚合跳转，不是已核实的原文链接；仅保存标题元数据，不保存或复述正文。数据卡自报 MIT，但不意味着获得所有出版商文章的复制和再分发权。该新闻数据集构建于 2026 年，日期与标题的历史修订无法独立证实，且不能证明它在当时可通过此数据集获得。

## 时间与复权：用于严谨历史回放前必须处理

1. **新闻**：源仅给日期，时区和具体发布时间未知。`published_at` 留空；`available_at` 是“所报告日期之后第 2 个日历日 00:00 UTC”的规则派生值。假设源日期正确、时区处于 UTC−14 至 UTC+14，该值晚于该日期可能的最晚结束时刻；它不是实际发布时间，亦不能证明源日期或后续修订准确。回放必须按 `available_at <= decision_time` 过滤。最后几天的新闻可能跨到 2026 年后才可见。
2. **SEC**：`acceptance_at` 为 SEC 记录的接收时间，按 accession 关联财务事实；报表的 `period_end` 不是发布日期。`published_at` 留空，`available_at` 设为接收后 1 小时的操作性延迟，并非精确披露时间，也不能保证所有文件届时已传播。需要严格实时可得性研究时应另寻实际传播时间并核验；不可把接收时间或报告期当作已核实的发布时刻。每个修订按自身的接收时间过滤，不得把后来修订向前填充。季度值可能为累计区间，不能把所有值直接当单季或 TTM。缺乏可用事实时留空，不可提前向前填充。
3. **行情及指标**：Yahoo 接口返回的 OHLC 字段是供应商报告值，并非历史未复权名义成交价。已实际检查 NVDA：来源记录 2024-06-10 发生 10:1 拆股，6 月 7 日收盘为 120.888 美元、6 月 10 日收盘为 121.79 美元，拆股前数据已经处于拆股后的价格量级；6 月 7 日 adjusted close 为 120.5443，与 close 不同。绝不能对这些已反映拆股量级的行情再次机械应用同一次拆股。该例支持拆股调整已反映，但不能证明所有股票与日期的完整调整口径或历史修订。它及 `adjusted_close` 都是今日下载快照，可能含拆股处理和事后修订，不能证明过去时点能看到相同值。快照没有历史每次修订的时间；因而不能将本包称为完全 point-in-time。不得仅用本包截断于 2025 年的拆股事件反推历史名义价：供应商快照还可能反映 2026 年及以后发生的事件，必须取得截至快照的完整事件并验证。价格、拆股、分红和成交核算策略必须先单独验证，避免复权、拆股、分红重复计算；不应直接拿 `adjusted_close` 同时作为实际成交价和现金分红依据。日线指标只在当日日线可靠可用之后使用，不能用于当天开盘或日内。
4. `event_at` 对 SEC 是报告期或事件日期，对新闻为 null；都不替代 `available_at`。新闻和 SEC 申报是两类证据，8-K item 仅是申报类型/元数据，不能当成已抽取的新闻正文或财报解读。股票池、来源及后续大模型本身可能带来历史结果泄漏。
5. **不提供凭空估值**：虽然有 XBRL 事实和行情指标，P/E、TTM 等需要处理会计期、单位、修订、股数和复权，现未构造；不能将累计值直接相除冒充指标。

## 来源和复现

- Yahoo Finance chart API：`https://query1.finance.yahoo.com/v8/finance/chart/{SYMBOL}`，interval=1d，2022–25，events=div,splits，包含 adjusted close；供应商 [复权说明](https://help.yahoo.com/kb/SLN28256.html)。API 是可获得快照，不代表本项目取得再分发或商业使用权；使用前核对供应商条款。响应完整保存在本地。
- [SEC EDGAR API 文档](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)：`data.sec.gov/api/xbrl/companyfacts/CIK{CIK}.json` 与 `data.sec.gov/submissions/CIK{CIK}.json`；包括覆盖期需用到的 submissions 分片。未下载公司公告正文，也未从中推断未经披露的信息。官网公开访问需遵循 SEC 访问政策和限速。
- [AlfonsoLozana/news 数据卡，固定 revision](https://huggingface.co/datasets/AlfonsoLozana/news/tree/6440e2333bfa0ec38b5ef46315e25dfb91a941da)：来源日期为日期级，标题或公司映射存在噪声；源声明的许可范围不保证第三方新闻权利。完整文件 SHA-256、下载时间及来源 URL 记录在 `news_source_receipt.json`。

脚本 `scripts/collect_research_data_3y.py` 下载 Yahoo 与 SEC 并生成行情、指标、公司行为、事实与申报；已有原始文件会复用；若重新下载形成新快照，应另存目录并重新固定哈希，不得覆盖已有实验的数据。`scripts/collect_research_data_3y_news.py` 使用 pyarrow，从已保存的元数据或固定版本完整 parquet 生成新闻与事实证据；需要 Python requests、pyarrow。若从完整来源重建，可按 receipt 的 URL 将文件保存为 `raw/news_source.parquet` 并核对 SHA-256。先执行采集脚本，再运行新闻脚本，最后执行 `scripts/collect_research_data_3y_validate.py` 并刷新 manifest。新闻脚本可仅用已保存的筛选前元数据重建相同 JSONL；本次重复运行的证据 SHA-256 完全一致。

自动验证检查各股票年度日线数量和日期一致、OHLCV 基本约束、重复证据 ID、实际匹配到 SEC 接收时间、延迟规则、新闻日期延迟规则、每年新闻/申报/财务覆盖。它不是与交易所逐笔数据或出版商原文逐条交叉核对，也没有运行交易 Agent、回测、付费调用或下单。
