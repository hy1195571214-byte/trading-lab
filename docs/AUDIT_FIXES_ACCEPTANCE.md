## 行为约定与兼容边界

- 前向模拟的 `fill_at` 使用实际处理合格报价的单调时钟；来源 bar、原接收时间、可用时间和观察时间分别保留。不补造过去的前向成交。
- 前端成交可见时间为成交时刻与来源行情观察/可用时刻中的较晚者；旧成交缺少这些元数据时回退到原成交时间。本轮没有改写既有实验以补造缺失信息。
- 费用未知的调用不按零费用处理。已配置的 token 价格用于保守预留；缺少价格或未知费用记录无法可靠核算时，会阻止继续调用并保留原因。重试可能再次调用提供方，但每次尝试都有记录并占用相应预算。
- 所有验证使用临时数据库、合成数据、确定性演示或受控 mock。没有调用真实 LLM/行情、支付费用或提交券商订单，也没有迁移或改写项目已有实验数据库。
- 这些结果证明本轮回归范围内的本地流程正确性；不证明交易盈利、人类监督收益或真实分钟行情与模型连接已经验收。原审查中的固定研究协议、主动审核耗时、分钟基准、完整研究报告及 TradingAgents 集成仍是后续工作。
