# Trading Lab 列表内部滚动验收

验收日期为 2026-11-10。本轮使用本地 5176 前端与隔离的 8004 后端，实验为 `57e3115b-5733-48a9-8ed7-ecc6a84e8f63`，名称为 `SYNTHETIC workflow UI fixture`。

## 实现范围

- `ScrollRegion` 默认将集合高度限制为 `32rem` 与 `52vh` 中的较小值。内容发生实际溢出时提供键盘焦点，垂直溢出时启用滚动边界限制。短集合自然收缩。窗口、内容尺寸和详情展开状态变化后重新检查溢出。
- 总览近期实验、实验登记、专家库、审核队列、持仓与订单、报告选择与比较、报告审核与用量、活动记录、采集器和数据集清单使用此组件。
- 决策流程面板中的数据包和运行记录使用此组件，审核风险位于可展开详情。本轮侧重通用组件与既有页面，新增阶段摘要面板由随后整体验收覆盖。
- 交易台右侧复用同一个组件作为原有 `tabpanel`，保留 `id`、`role` 和 `aria-labelledby`。`bounded={false}` 使其高度交由原有工作台布局管理。交易台下方持仓表独立使用默认高度限制。

## 实测发现与修复

1. 右侧详情外壳继承了网格布局。长内容时外壳被限制为 700px，内容本身的可见高度和总高度却同时达到 1677px，外壳裁剪了下方内容。为外壳明确设置纵向 flex 布局后，内容区域高度为 655px，总内容高度仍为 1677px，滚轮和键盘均能访问下方内容。
2. 右侧详情原先持续设置滚动边界限制。短内容高度和总高度均为 233px 时，滚轮仍会阻止页面滚动。该区域改为复用动态溢出检测后，短内容恢复 `overscroll-behavior-y` 为 `auto`，同时移除额外焦点入口。

## 长列表构造方法

隔离数据库中的真实记录数量较少。为了在实际页面中检验长列表，本轮在浏览器 DOM 中为现有表格或专家网格临时追加 40 个克隆条目，并标记为 `SYNTHETIC scroll fixture`。克隆控件禁用，只用于布局和滚动压力测试。交易台右侧临时追加 45 行明确标记为合成的段落。

短列表传播测试在页面末尾临时增加 1000px 空白，使页面具备可滚动距离。记录滚轮操作前后的区域 `scrollTop` 和 `window.scrollY`，随后移除测试节点。所有操作都在现有组件和真实浏览器布局中执行，滚轮使用真实鼠标 wheel，键盘使用 Tab、ArrowDown 和 PageDown。

这些临时条目仅存在于浏览器 DOM，数据库保持原有合成实验。结束时测试节点数量为 0。验收期间只浏览已保存记录，未启动实验、模型调用或回测。`data/research_3y` 数据未参与此次验收。

## 短内容、空状态与操作

- 单条实验列表的区域高度和内容高度均为 103px，`tabindex` 为空，滚动传播为 `auto`。真实滚轮使区域位置保持 0，页面位置由 0 增至 220px。
- 右侧详情短内容的区域高度和内容高度均为 233px，`tabindex` 为空，滚动传播为 `auto`。真实滚轮使区域位置保持 0，页面位置由 0 增至 160px。
- 专家搜索输入无匹配词时显示原有空状态，区域高度和内容高度均为 76px，焦点入口为空，滚动传播为 `auto`。清空搜索后专家卡片恢复。
- 持仓与订单在该合成实验中均为空，各自区域高度为 44px，保持无额外焦点入口。采集器保持原有空状态。
- 原始实验的比较复选框能使选择计数在 0 和 1 之间切换。打开原始实验进入有效合成交易台。中英文切换同时更新区域名称。上述操作使用原始控件。
- 长实验列表可通过实际 Tab 进入区域，ArrowDown 可增加区域位置。右侧长详情可从选中标签页通过 Tab 进入，并使用 PageDown 继续内部滚动。
