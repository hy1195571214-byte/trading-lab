| 工作区 | 总览、交易工作台、持仓与订单 | 继续运行、审核建议、查看订单 |

## 三条主要用户路径

1. 创建实验：总览 → 实验列表 → 市场与数据 → 专家团队 → 风控与审核 → 交易工作台。
2. 人工监督：工作台或审核队列 → 决策证据 → 批准／修改／拒绝 → 结果确认 → 订单／活动记录。
3. 专家组合：专家库 → 详情 → 分配角色 → 下次决策生效 → 工作台查看意见与汇总结果。

## 关键操作规则

### 专家卡片

- 明确区分交易员与顾问。顾问不直接下单，系统最终只形成一份订单计划。
- 展示名称、版本、策略目标、适用周期、必要数据及风险偏好。
- 添加、移除、启停与角色调整在下一决策边界生效。
- 若有待审核建议，用户需明确选择保留当前团队完成审核，或废弃尚未执行的建议并重新分析。
- 缺少必要数据时阻止激活并给出补充数据／换策略入口。
- 自定义卡片先保存版本，再进入实验；测试输出应标注样例或实际调用来源。

### 历史回放与运行

- 时间轴仅显示当前回放时点已可见的信息。
- 启动前检查数据、资金、模型连接及预算；冻结实验配置和输入版本。
- 暂停停止新的决策和提交；保留现有持仓及记录。
- 步进进入下一个决策时点；如需审核则暂停等待用户。
- 运行中更换监督模式，创建新的实验分支，不覆盖旧配置。
- 模型失败、无效输出和预算耗尽均暂停，不虚构决策。

### 审核与执行

- 审核页同时展示原始建议、持仓影响、专家分歧及证据来源。
- 修改和拒绝需填写原因；同时保留原始建议与人工操作。
- 超过仓位、资金等硬限制时禁用提交，提示具体限制及修正方式。
- 批准表示进入待执行状态，不代表已经成交；仍按约定时点和费用规则执行。
- 拒绝不会自动卖出现有持仓，也不会创建替代订单。

### 报告、数据与设置

- 对比前检查日期、资产、资金与成本；差异需披露。
- 报告包含收益风险、费用、人工介入次数与时间、配置版本及局限。
- 数据导入产生新版本，不替换运行中实验的历史快照。
- 密钥始终遮挡，不出现在日志、导出或原型演示中。
- 设置更新默认只影响新实验，修改已有实验需显式分支。

## 组件与状态

- 按钮：主操作、次操作、弱操作、危险操作、悬停、键盘焦点、禁用、加载。
- 输入框：默认、焦点、校验错误、禁用；配标签与辅助文案。
- 标记：中性、激活、成功、警告、失败。
- 选择：开关、复选、角色选择、筛选、日期与时间回放控件。
- 业务组件：指标卡、资产曲线、专家工牌、审核面板、数据表格、证据列表、审计时间线。
- 通用状态：空白引导、加载、连接成功、数据阻塞、模型失败、操作确认、导出完成。

## 原型边界

Figma 用于检验页面层次、点击路径及代表性的状态转换。表单自由输入、上传文件、真实 LLM 调用、实际回测及报告文件生成属于后续平台实现，不应将原型确认画面当成真实执行结果。

## 行情视图补充（2026-11-09）

依据用户提供的同花顺分时与日 K 截图，基础行情看板区分以下视图：

- **分时**：所选交易日截至回放时点的价格折线，下方保留成交量；有日内数据时默认进入此视图。横轴固定为交易日开盘到收盘，已有价格线从左向右延伸，未来时段留白，不随数据点数量拉伸；成交量、悬浮线及交易标记使用相同的时间坐标。当前基础版明确展示美股常规时段 09:30–16:00 ET，未接交易日历前不声称识别半日市或其他市场时段。
- **日 K / 周 K**：按对应周期显示 OHLC 蜡烛图和成交量，不将分钟蜡烛图仅改名为日 K 或周 K。周期汇总仅使用所选时点已可见的数据，明确标注可能不完整的覆盖。
- 没有日内数据时不虚构分时走势，日线数据默认日 K。
- 周期切换仅改变行情展示，不改变 Agent 决策频率、实验配置或账户回放时点。鼠标悬浮只改变行情读数；点击 K 线只锁定行情读数，不改变回放时间。回放跳转由时间控制或明确的来源导航（例如“查看来源建议”）触发。
- 保留已确定的黑灰底、黄绿色强调、常驻持仓表及 Agent / 专家标签页。基本功能不包括五档、盘口深度、额外技术指标或截图中的推广模块。


### 行情涨跌配色（2026-11-10）

- 图表遵循红涨绿跌：上涨红 `#E27D76`，下跌绿 `#80D5A1`，持平灰 `#929B8D`。
- 分时成交量按本分钟收盘价与上一分钟收盘价比较；当天首分钟与本分钟开盘价比较。此颜色表示价格方向，不表示主动买入量或卖出量。
- 日 K / 周 K 的蜡烛与成交量按对应周期收盘价相对开盘价着色；分时价格线继续使用黄绿色。


## 语言与列表滚动补充（2026-11-10）

- 提供中文和 English 的界面切换，并在本机保存选择；更新页面语言与无障碍标签。实验名、模型输出、用户输入、数据来源和原始错误详情保留原文，使用可翻译的标签说明其性质。
- 大多数长列表采用有高度上限的内部滚动容器，表头保持可见；实际溢出时可通过键盘聚焦并滚动。短列表不吞掉整页滚动，不统一锁死整个页面。
- 交易台右侧标签页沿用一个滚动区域，避免嵌套容器；标签栏保留在上方。侧栏折叠与小桌面窗口下，主体布局继续适配。
- 决策流程页按实验名称选择，显示已保存的阶段、证据覆盖、建议仓位、风险与人工审核摘要；原始记录放入可展开详情，演示结果仍明确标识。
- 新实验可选择证据包及基础组合限制，配置只在新实验中冻结生效。历史回放的下一有效开盘成交与实时模拟的下一观察收盘成交应分别说明。

## 用户可调融合权重的设计确认（2026-11-10）

本节约定分源评分融合界面的交互，已纳入四模式本地初版。

- 在实验配置中提供行情、新闻、财务三项融合权重，每项采用 0% 至 100% 滑块与数值输入，显示合计值。合计达到 100% 且各项有效时允许保存。
- 决策详情展示各 Agent 的评分、用户权重、加权贡献及最终综合分，并显示所用权重版本和信息可用状态。
- 运行中调权显示当前生效值和待生效值，提交时说明在下一次新决策开始时应用。当前在途或待审核建议展示生成时的权重。
- 保存调权记录，并在人工干预统计中单独列出调权次数和生效时间。历史详情按照当时保存的权重展示。
- 具体实现遵循 `PROJECT_CONSTRAINTS.md` 第 11 节。

## 四模式界面接入（2026-11-10）

- 创建向导提供开源量化、行情 Agent、多源 Agent、人机协同四模板，保留原有专家团队实验入口。服务能力确认后开放模板创建。
- 四模板共用工作台，显示策略或来源分析、证据方向分、加权贡献、目标仓位和介入历史。量化模板显示上游来源与规则记录。
- 人机模板显示当前与待生效权重，逐笔审核操作继续展示原建议与人工结果。报告分别展示调权请求、已生效与待生效数量及交易审核。
- 工作台顶部采用紧凑上下文，移除占据主要空间的页面大标题和实验 UUID，必要的实验名称、模式及数据性质以易读方式展示。完整标识仍可在详情和审计中查阅。

## 多股票回放与持仓展示补充（2026-11-10）

- 回放中切换主图股票、增加对照股票及折叠图表时继续播放，全部图表共用所选回放时点，按纵向排列显示。每张图表独立选择周期、显示范围及展开状态。
- 图表可向上收起，保留股票名称、回放价格与涨跌。时间跳转和来源导航沿用显式暂停规则。
- 量化说明按信号条件、仓位分配、成交时序、入选股票分类展示，代码来源、许可、提交与规则原文放入可展开的复现详情。原始建议以操作摘要、目标仓位表及比例条展示，并标明待执行含义。
- 持仓标记价、市值和浮动盈亏按所选时点价格相对平均持仓成本着色，红涨绿跌，持平和未知为灰色。旧快照可用当时已可见成交重建平均成本，须核对股数一致并标注来源，滑点包含在成交价中，单列手续费另计。
- 持仓表下方用环形饼图和图例展示股票市值及现金占比，随回放时点同步更新，缺失或零资产状态提供说明。

## 交易风格卡片：唯一系统提示词入口（2026-11-23）

- 风格实验通过选择／切换主交易卡片设置交易理念与决策原则，展示卡片版本及实际生效的系统提示词版本；卡片切换在下一次新决策生效。
- 此路径不提供来源／因子权重滑块或加权买卖阈值作为风格控制。分析员保持统一证据口径，由带风格系统提示词的主交易 LLM 综合判断并输出交易建议。
- 风控设置与卡片分开呈现，继续显示程序执行的现金、仓位、敞口、换手与成交限制；目标仓位比例作为 LLM 建议展示，人工批准、修改、拒绝继续单独记录。
- 历史加权实验保留原权重与干预记录，明确标识其决策机制；不将旧实验展示为已遵循新的风格 LLM 路径。
- 实际界面迁移及验收待后续实施，不能将本规范更新作为功能已完成的证据。
